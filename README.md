# telnes.de

The website at [telnes.de](https://telnes.de). Plain HTML, hosted with GitHub Pages.

- `logo.svg` (white with black outline) and `logo-dark.svg` (black with white outline): the telnes logo, set in Dancing Script Bold with a hand-added lead-in on the t, with the letters converted to outlines.
- Fonts: Hanken Grotesk, under the SIL Open Font License (see `fonts/`), stored here so visitors' browsers don't contact any font service. Dancing Script (also SIL OFL) is only used as outlines in the logo.
